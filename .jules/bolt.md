## 2024-07-01 - Optimizing Printify API bottlenecks
**Learning:** Using `@functools.lru_cache` to memoize repetitive API queries inside loops is highly effective for reducing N+1 API bottlenecks. However, when returning lists from cached API responses, the lists can be accidentally mutated by downstream functions since references are shared. Python's `json.dumps()` natively serializes tuples into JSON arrays, allowing tuples to be safely used as drop-in replacements for lists in API payloads while ensuring immutability for cached data.
**Action:** When caching third-party API query functions, cast list responses to immutable tuples and update type hints to `tuple`. This guarantees thread-safety and avoids unexpected downstream state mutations while remaining perfectly compatible with JSON payloads.
