## 2026-10-23 - Memoize Printify Variant API Calls
**Learning:** In the Printify product creation pipeline, calling the variants API endpoint (`/catalog/blueprints/{blueprint_id}/print_providers/{provider_id}/variants.json`) is a static operation per blueprint/provider combo, but is executed repeatedly in iterative product creation loops (e.g., N+1 query problem). Python's `@functools.lru_cache` resolves this, but since lists are mutable and not cache-safe for downstream mutation, returning a `tuple` ensures both performance and thread-safe immutability.
**Action:** Use `@functools.lru_cache(maxsize=None)` for static 3rd-party API queries in loops, and cast the return types to `tuple` instead of `list` to prevent accidental downstream state mutation from shared cached references. Update type hints accordingly.
