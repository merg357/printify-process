## 2026-10-17 - Memoize Printify blueprint variants API to avoid N+1 queries
**Learning:** During iterative product creation across multiple designs, calling a third-party API (like Printify's variants endpoint) for each product results in severe N+1 network bottlenecks. Repeated identical requests for the same blueprint_id and print_provider_id drastically slow down the batch process.
**Action:** Use @functools.lru_cache(maxsize=None) to memoize static/infrequently changing API responses within bulk processing loops. Always return an immutable structure like a tuple instead of a list when caching parsed JSON data to prevent thread-safety issues or unintended downstream mutations from shared references, and remember to update type hints to built-in lowercase types like tuple[int, ...].
