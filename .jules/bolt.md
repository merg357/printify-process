## 2024-05-24 - Memoize Printify Variant Queries
**Learning:** Found an N+1 query problem in the merchandise creation pipeline across multiple scripts (`printify_manager.py`, `merch_factory.py`, `create_merch.py`). The scripts query the Printify API for blueprint variants on *every* product created. Since variants for a specific blueprint and print provider are static for the duration of a run, this results in significant unnecessary network latency when generating multiple products (e.g. iterate over 10 images * 3 blueprints).
**Action:** Use Python's `@functools.lru_cache(maxsize=None)` to memoize static third-party API queries like `get_variants`. When memoizing functions returning mutable types like lists, always cast the return to a `tuple` to ensure thread safety and prevent downstream state mutations, updating type hints appropriately.
