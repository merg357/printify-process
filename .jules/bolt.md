## 2024-05-24 - Elimination of N+1 Network Bottleneck via Immutable Memoization
**Learning:** In bulk operation scripts (like creating products from blueprints), fetching variants repeatedly for the same blueprint creates a severe N+1 network bottleneck. Applying `@functools.lru_cache` solves this, but if the cached function returns a mutable object (like a parsed JSON list) and the downstream code modifies it, it can lead to state mutation bugs across iterations. Python's `json.dumps()` natively serializes tuples into JSON arrays, allowing tuples to be safely used as drop-in replacements for lists in API payloads.
**Action:** Always cast the return value of memoized third-party API query functions to an immutable type (like `tuple`) before caching, and ensure type hints are updated accordingly (e.g., `-> tuple` instead of `-> list` or `-> List[int]`).
