This can lead to severe rate-limiting and major script slowdowns because standard functions like `get_variants` were hitting the network on every iteration.]\n**Action:** [Memoize these functions with `@functools.lru_cache(maxsize=None)` for the lifetime of the script to prevent duplicate outbound network requests and speed up operations significantly.]
