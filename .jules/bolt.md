## 2026-08-27 - Printify Blueprint API N+1 Mitigation
**Learning:** The codebase's batch product creation loop frequently fetches static blueprint variants from Printify's API. This causes severe N+1 network bottlenecks as the same blueprint variants are queried repeatedly across multiple products. When applying `@functools.lru_cache` to mitigate this, the API response must be cast from a mutable list to an immutable `tuple` to guarantee thread-safe cached returns and prevent downstream state mutations from shared references, while remaining compatible with `json.dumps` during payload construction.
**Action:** Always wrap redundant third-party API static data fetches in product creation loops with `@functools.lru_cache` and strictly cast list returns to tuples to enforce immutability.
